### Условие задачи:

**Выбор маршрута**

На развилке дорог стоит знак. Он показывает направление "Налево", если только одно из двух чисел (A или B), полученных от датчиков traffic flow, является четным. Запишите условие для показа направления "Налево".

## **1. Алгоритм и блок-схема**
Алгоритм
1. Начало
2. Ввести переменные:
int a, b, c;
3. Предложить пользователю ввести значение переменных a и b (датчиков traffic flow):
puts("Перед вами знак, указывающий направление\n");
puts("Введите значение датчиков traffic flow (a и b):\n");
4. Принять введенные значения переменных a и b:
scanf("%d %d",&a,&b);
5. Записать условие для направления "Налево":
c = (a%2==0 && b%2!=0) || (a % 2 != 0 && b % 2 == 0);
6. Вывести результаты расчетов на основе введенных данных с подстановкой всех значений в текст.
printf("\nЗнак указывает направление (1 - Налево, 0 - Направо): %d\n", c);
7. Конец
